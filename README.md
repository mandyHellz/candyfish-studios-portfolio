# Candyfish Studios Portfolio

A **legacy front-end portfolio project** built with **Next.js, TypeScript, Tailwind CSS and Framer Motion**, focused on layout composition, animations and responsive design.

🔗 **Live Demo:**  
https://candyfish-studios-portfolio-9v81eylv1-mandyhellz.vercel.app

---

## Purpose

This project was created as part of my early journey into front-end development, aiming to consolidate concepts related to:
- Responsive layouts
- Component-based UI structure
- Page transitions and animations
- Visual presentation of a portfolio-style website

Although originally developed several years ago, it is kept public as a reference to my evolution and learning process in front-end development.

---

## What this project demonstrates

- Page composition using React and Next.js
- Responsive design with Tailwind CSS
- Basic animation and interaction using Framer Motion
- Component reuse in a real UI context
- Deployment and hosting with Vercel

---

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

---

## Background

This project was built during a front-end course focused on React and Redux fundamentals.  
The structure, styling decisions and overall composition were implemented independently based on the concepts learned.
